# Lillian (Liangyan) Li — Academic Website

Personal research website built with the Academic Pages / Minimal Mistakes template and hosted on GitHub Pages.

- `_pages/about.md`: biography
- `_pages/research.md`: research themes, projects, and future directions
- `_publications/`: publication records
- `_pages/experience.md`: academic visits and industry experience
- `_pages/teaching.html`: teaching experience
- `_pages/cv.md`: web CV
- `_data/navigation.yml`: navigation
- `_config.yml`: sidebar and site settings

Email and telephone are intentionally omitted. Preprints link to their public landing pages without direct PDF downloads.
